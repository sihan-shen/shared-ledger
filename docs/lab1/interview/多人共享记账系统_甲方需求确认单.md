## 三、关键规则核对

以下内容依据前两轮反馈整理，供本次核对。未在本节列出的字段限制、查询条件及操作细则，后续在详细需求文档中逐条呈现。

| 编号 | 规则摘要 |
| --- | --- |
| B01 金额与精度 | 支出金额为 0.01—99,999.99 元，最多两位小数；不允许零、负数和未来发生日期。分摊总和必须等于总金额。 |
| B02 平均分摊 | 先按分向下取整，剩余的分按参与者首次加入账本的固定顺序分配。指定金额分摊可将某人设为零。 |
| B03 支出状态 | 保存即生效；作废需写原因，不可恢复；作废记录保留，但不计统计或余额。 |
| B04 支出更正 | 普通成员可更正本人录入的支出，管理员可按权限更正他人支出。退款更正专属管理员；相关原因、分配结果及历史版本留存。 |
| B05 净余额 | 净余额＝实付支出－承担支出＋已确认付出的还款－已确认收到的还款。正数为应收，负数为应付；全部成员合计为零。 |
| B06 统计时间 | 消费统计按发生日期筛选，采用北京时间自然日和自然月；净余额始终按整个账本累计。还款不计消费，历史支出更正按原发生日期回算。 |
| B07 待确认还款 | 占用付款方可付额度和收款方可收额度；确认时排除该笔自身占用。仅已确认还款影响余额，不自动超时确认。 |
| B08 超额处理 | 余额变更后统一校验。某成员某方向的待确认总额超限或方向失效，撤销该方向全部待确认单，不自动改小金额；余额变更、校验和必要撤销整体生效。撤销范围的统一计算方式见 C02。 |
| B09 已确认还款纠错 | 采用独立申请，由原付款人发起、原收款人处理，管理员不能代办；处理中原还款仍有效。同意后只冲回一次。部分金额错误时，撤销原记录并生成正确金额的已确认更正记录，两项一起生效并关联留痕。 |
| B10 真实退钱 | 保留实际发生过的原还款，另记反向还款；不得同时撤销原记录并对同一笔资金退回重复冲账。 |
| B11 退出成员 | 可见账目按首次生效时间早于退出时间划分。保留历史查看权；不能新增、修改日常支出。历史更正产生往来后，可处理本人相关还款及纠错申请，不开放新账、全账本实时统计和无关日志。 |
| B12 历史人员更正 | 仅能保留当前版本已有的退出付款人或承担人，允许调整金额、设为零或移除；移除后不得重新选择，除非该成员重新加入。 |
| B13 归档与管理权 | 所有相关成员余额为零、无待确认还款及处理中撤销申请，方可归档。归档后仅按权限查看及由管理员重开；其他业务先重开。账本始终至少有一名在册管理员。 |
| B14 邀请 | 登录后使用不绑定账号的邀请链接，7 天有效、单次成功加入后失效；重复成员不消耗名额。归档、删除或邀请人失去管理员资格使未用链接失效，后续不自动恢复。 |
| B15 分类 | 各账本独立维护，管理员可新增、改名、停用，仅未使用分类可删除；改名后历史账和统计显示新名称，变更记录保留。 |
| B16 数据留存 | 业务数据及关联日志自账本最后一次业务变更起至少保留三年；单纯查看不重新起算。使用中账本不能因满三年删除。本期不开放数据清理和账号注销。 |
| B17 保存可靠性 | 成功后刷新、重新登录仍完整可查；中断保存只能完整成功或完全未保存，不能缺少分摊。相同操作重试不重复记账或冲账。 |
| B18 页面要求 | 中文界面，宽度 360—1440 像素范围内核心表单无横向滚动，正文至少 16 像素，错误有文字提示。具体设备及浏览器版本见 C05。 |

### C02　多方同时超额时，是否按同一组数据确定全部撤销记录？

为避免检查先后顺序导致不同结果，建议明确：

> 每次余额变更后，依据变更后的余额和当时全部待确认记录，一次确定所有超限或方向失效的成员及方向；撤销涉及这些方向的全部待确认记录。同一记录涉及多方时仅撤销一次。不能因先撤销部分记录释放了额度，就改变本次已经确定的其他撤销范围。

例如 A 当前应收 60 元、D 应收 40 元，B、C 各应付 50 元；待确认记录为 B→A 40 元、C→A 40 元、B→D 20 元。A 待收合计 80 元、B 待付合计 60 元，均超限，C、D 未超限。按上述规则，三笔都撤销；若先后检查并边检查边释放额度，则可能只撤销其中两笔。
