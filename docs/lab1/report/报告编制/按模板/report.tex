\section*{1 项目概况}
项目面向合租等多人共享记账，解决费用垫付、共同收入分配和往来结算难追溯的问题，目标是审核后生效、金额守恒、余额清晰、操作可查。本期包括账号、账本及三类权限、收支与更正、预算、组合查询、统计、线下还款和日志。不实现真实支付、资金托管、多币种、公共账户、银行同步、离线记账、比例分摊及多人付款；图片、导入导出、提醒和周期记账延后。本实验只做需求分析。

\section*{2 整体业务分析}
\subsection*{2.1 主要业务流程}
管理员建账本、邀请并授权；成员保存草稿、本人提交，合格审核员通过后更新统计、预算和余额，驳回或本人撤回后修改重提。录入人或申请人不能自审。付款人线下支付并登记还款，收款人确认到账；管理员检查余额及待办后归档。退款由管理员申请更正或作废原支出，保留真实还款。

\subsection*{2.2 主要数据之间的关系}
保存用户、账本、成员及角色、分类、收支版本与分配、审批申请、预算、还款及纠错和日志。用户经成员关联账本，同一账号同账本身份唯一；每笔收支或还款只属一个账本，分配合计等于金额。每笔收支最多一个生效版本、一项待处理更正或作废申请，每月预算设置唯一。业务变更与关联金额、状态、日志整体更新，失败全部回退。

\subsection*{2.3 业务状态和状态转换}
收支六状态：草稿→待审核→已审核；待审核可由本人撤回为已撤回，或由审核员驳回为已驳回；撤回、驳回后可修改重提。未生效记录按权限可作废，待审核须先撤回或驳回；已审核仅经独立申请更正或作废，已作废为终态。重复提交仅一次生效，旧版本冲突拒绝；非法金额、分配不平衡拒绝保存。

\section*{3 实验总结}
早期范围与完整任务书存在差异，通过追加问卷补齐审核员、收入、审核和预算。整理时区分录入人与付款人、申请与主记录、登记纠错与真实退钱，并用金额例子核算余额和预算。审查澄清了生效版本数量，补回评审材料提交节点；复核确认“统一精确到分”已有依据，避免把已有规则误判为未知。业务确认与资源待落实分别记录，角色恢复及金额边界经补充沟通确认。AI便于统一编号、字段、来源和验收条件，也会过度推断或混入执行日志，需对照原答复纠正。41条核对及8项代表记录由AI协助整理，乙方提出核查要求并转述甲方意见，不将其冒作独立人工签审或软件实测结果。
