## UML 目录

9 张图，`.puml` 与 `.png` 同名，覆盖：

- 结构性：类图（必画）、组件图、部署图
- 行为性：用例图、状态图 ×3、活动图
- 交互性：时序图

`UML/` 只放 PlantUML 的源文件与渲染图；架构参考图 `refs/architecture.png` 是 Graphviz 画的实现分层参考，不是 UML，未放入提交目录。

## UI 目录说明

- 当前 UI PNG 是用本地 HTML/CSS + headless Chrome 渲染的**视觉参考稿**，不是 Figma/Pixso 导出。
- 如果课程严格检查“使用 UI 设计工具”，需在 Figma/Pixso 中按这些稿重绘，再用同名文件替换；页面结构、文案、状态说明可直接沿用。
- 报告中的 17 个概念页面与文件对应关系：
  - 05 邀请加入并入 `界面04_成员与邀请` 右侧抽屉；
  - 09 账目详情由 `界面09_待审核详情` 覆盖，10 另有管理端待审队列；
  - 13 统计并入 `界面12_预算与统计`；
  - 09b/09c 是同一页面的 360/768 宽度检查稿，不额外算模块。
- 图片尺寸：移动端 780×1688（390×844 @2x），管理端 2160×1350（1440×900 @1.5x）；09b 为 720×1688，09c 为 1152×1350。
- 16px 正文的样张是 `界面09`、`界面06/07` 的表单值；正式 Figma 其余页面仍需按 16px tokens 重绘。
