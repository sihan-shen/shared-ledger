## 浏览器人工操作

使用本机 Chromium 内嵌浏览器，独立检查标签页操作内存示例：

| 操作 | 实际观察 |
| --- | --- |
| 金额填 `12.345`，说明留空，提交 | 显示金额精度与必填说明错误，并聚焦金额框 |
| 金额 `100.01`，说明“晚餐分摊”，A/B/C 均摊 | 分摊为 33.34/33.34/33.33；提交后出现在首页与审核列表 |
| 新增账目待审核 | 待审数量增加，正式预算仍为 680 元 |
| 选择本人录入账目 | 审核通过、驳回与意见框禁用，并展示独立审核说明 |
| 未填意见直接驳回 | 显示“请填写驳回原因” |
| 审核通过“周末聚餐” | 待审从 3 笔变 2 笔；预算 680→800 元；A/B/C/D 余额变为 +80/0/−80/0，合计零 |
| 上述余额变化后的原 50 元待确认还款 | 显示“已撤销”，占用额度归零 |
| 另一轮初始数据确认收款 50 元 | A 余额 +120→+70，B −80→−30；记录显示“已确认”，余额合计零 |
| 确认弹窗按 Escape | 弹窗关闭，焦点回到“确认已收款”触发按钮 |
| 搜索不存在的账目 | 队列和详情显示空状态；清除筛选恢复列表 |
| 资格筛选“我可审核” | 排除本人录入的账目 |
| 组件页切换基础件 / 业务件 / 视觉规范 | 正确展示对应组件、状态与 tokens |
| 顶部重置演示数据 | 恢复初始队列、余额与预算 |

开发中新增懒加载的导入位置曾导致一次刷新白屏，已修正；重新生产构建和完整加载后恢复。最终人工操作区间内浏览器日志没有新增 error。

## 尺寸与样式

代表页面检查：360px 首页/录入/管理工作台/组件页；390px 结算/录入；768px 管理工作台；1440px 管理工作台/组件页。实际页面 `scrollWidth` 不大于视口宽度，未发现整页横向溢出。

实际读取样式：正文与表格 16px、卡片圆角 8px、边框 1px；管理端可见 Button 最小高度 44px；卡片阴影为透明零尺寸；主色解析为 #0F766E。输入金额使用 30px 强调排版，其余输入遵循 16px。
